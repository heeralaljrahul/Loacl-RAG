# Information Security Policy

## Passwords and authentication

Passwords must be at least 14 characters. Scheduled rotation is no longer required; credentials found in a breach corpus are force-reset instead. Hardware security keys are mandatory for anyone with production access.

## Devices

Full-disk encryption is mandatory on every laptop. Lost or stolen hardware must be reported within 4 hours to the security desk, which will issue a remote wipe.

## Vendor access

Third-party vendors receive time-boxed access of at most 14 days. Every vendor account is reviewed quarterly and revoked automatically if unused for 30 days.

## Incident response

Suspected incidents go to security@acme.example within one hour of discovery. The on-call security engineer owns triage; the communications lead owns any external statement.
